# Node как рантайм и единый бинарь через pkg

Требование «на хосте не появляется ничего, кроме openstrap и гипервизора» означает поставку одним самодостаточным файлом, поэтому рантайм надо выбрать до первой строки кода этапа A. Выбран Node: код уже написан на Node с `tsx` и `vitest`, сборка единого бинаря тем же тулчейном уже работает в `workloads` через `@yao-pkg/pkg`, а SQLite доступен встроенным `node:sqlite` без нативных модулей.

## Considered Options

Bun давал `bun build --compile` из коробки и `bun:sqlite`. Отклонён: единственное преимущество - сборка бинаря - уже закрыто через `pkg`, а цена - переезд всего работающего кода и тестов. [#18](https://github.com/yardencom/openstrap/issues/18) описывает скелет CLI на Bun и подлежит правке, а не исполнению.

## Consequences

Нативные модули избегаются, потому что ломают сборку бинаря. Это ограничение распространяется на плагины: встроенный SSH-клиент должен быть на чистом JS.
