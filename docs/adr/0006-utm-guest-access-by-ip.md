# Доступ к гостю UTM - по IP, не по проброшенному порту

Провайдер UTM получает адрес гостя через `utmctl ip-address` и подключается к нему напрямую в сети `shared`. Проброс порта не используется.

Причина фактическая, а не архитектурная: через scripting UTM не устанавливается ни одна коллекция - ни `network interfaces`, ни `drives`, ни `qemu additional arguments`. Свойство `qemu port forward` объявлено в `UTM.sdef` и не применяется. Проверка записана в `docs/wiki/grill/utm-scripting-probe.md`.

## Considered Options

Правка `config.plist` внутри пакета `.utm` до первого запуска дала бы стабильный `localhost:<порт>`. Отклонена: это обход официального API, который ломается при смене формата UTM, то есть workaround, а не решение.

Смена бэкенда на `apple` не рассматривается как выигрыш: доступ там тоже строится по IP, а `uefi` и аппаратное ускорение для загрузки Ubuntu-образа нужны. Единственное преимущество `qemu`, названное в issue #29 - проброс порта - не существует, но и недостатка у `qemu` относительно `apple` тоже не появилось.

## Consequences

Endpoint машины не постоянен. IP выдается DHCP в сети `shared` и может измениться между загрузками, поэтому endpoint не кешируется в lock-файле и перечитывается у провайдера при каждом обращении. Это совпадает с уже принятым правилом: фактическое состояние машины openstrap не хранит.

`utmctl ip-address` отвечает через QEMU guest agent, которого в облачном образе Ubuntu нет. Cloud-init обязан установить `qemu-guest-agent`, иначе адрес не получить. Ожидание адреса становится отдельным шагом создания - ограниченным по времени и повторяемым, потому что это временное состояние загрузки, а не постоянная ошибка.

Выделение портов на хосте перестает быть обязательным для SSH. Таблица `allocated_port` в state store остается: она нужна там, где порт действительно занимается на хосте, но путь `create` для UTM ее не заполняет.

Провайдер обязан открыть окно UTM перед любой мутирующей командой: пока окон ноль, scripting отвечает `UTM is not ready to accept commands (-2700)`, хотя чтение работает.
