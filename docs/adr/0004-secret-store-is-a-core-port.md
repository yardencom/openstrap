# Secret store принадлежит ядру, не плагину

Приватный ключ управляемого пользователя генерирует и хранит ядро через порт secret store, у которого есть вторая настоящая реализация - keychain и GPG. Плагин transport получает ссылку на секрет, а не значение.

## Consequences

Плагин `@openstrap/ssh` не работает с keychain и не владеет ключом: правило «плагины получают ссылки на секреты, не значения» иначе нарушается тем же плагином, который его должен соблюдать. В cloud-init уходит только публичный ключ.
