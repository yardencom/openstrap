# Lock-файл и state store хранят разное

`openstrap.lock.yaml` содержит только то, что одинаково у всех, кто склонирует репозиторий: разрешенный образ, его sha, формат, boot mode, версии плагинов. Локальное состояние - выделенные порты, id ресурсов провайдера, прогоны, снимки фактов - живет только в state store. Разделение проходит по природе данных: sha образа переносим между людьми, а id машины в UTM и занятый порт верны только на одной машине.

## Consequences

Lock-файл коммитится в git и дает воспроизводимость. Он не является отчетом, производным из базы, поэтому в него не утекает ничего машинно-локального. Обратное разделение - «база источник истины, lock генерируется из нее» - сделало бы lock-файл в git разным у каждого разработчика.
